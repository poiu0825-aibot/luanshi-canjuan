# 亂世殘卷

東方奇幻 Roguelike 網頁遊戲。網頁入口為 `index.html`，搭配設定檔、資料表與 `assets` 素材；本機遊玩時請下載完整儲存庫，不能只下載 HTML。

## 遊玩

開啟本儲存庫的 GitHub Pages 網址即可遊玩。遊戲存檔保存在玩家目前使用的瀏覽器中；清除網站資料或更換裝置前，請先使用遊戲內的存檔匯出功能備份。

## 版本維護

- 發布檔固定為 `index.html`。
- 每次更新同步修改遊戲內「更新內容」與 `CHANGELOG.md`。
- 版本號採 `主版號.功能版號.修正版號`。
- GitHub 的每次提交會保留歷次程式版本。

目前版本：v0.22.1

平衡與內容維護請參考 [`DATA_MAINTENANCE.md`](DATA_MAINTENANCE.md)。
